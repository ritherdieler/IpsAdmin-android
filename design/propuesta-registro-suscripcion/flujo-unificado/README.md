# Flujo propuesto de registro de suscripción

Secuencia de mockups conceptuales. Todas las pantallas usan el mismo indicador lineal de cinco segmentos y el contador `n de 5`.

1. Ubicación y cobertura
2. Datos del titular
3. Servicio y plan
4. Equipos y conectividad
5. Revisión y registro

Los nombres, direcciones, DNI, planes y estados de cobertura son datos ficticios de muestra.
