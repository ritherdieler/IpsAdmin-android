# Design system

El design system de IspAdmin es uno solo para la app Android y el back office web, y vive en el artifact **«IspAdmin»**: https://claude.ai/artifact/T4ssmVpou5P4pvcFkjS6sF.

Esta carpeta guardaba una copia de su versión del 2026-10-11 (solo el dashboard). Desde el 2026-10-22 la copia se retiró para que no haya dos fuentes: los tokens, los componentes y la correspondencia con `presentation/theme/` (`Color.kt`, `IspColors.kt`, `IspType.kt`, `Dimens.kt`) están en el artifact, sección «Plataformas».
