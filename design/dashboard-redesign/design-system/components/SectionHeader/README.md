SectionHeader titles a group of cards on the dashboard and can carry one trailing text action.

- **Consumer provides:** `title`, optional `caption`, optional `actionLabel` + `onAction`.
- Title in `title-lg` / `on-surface`, caption in `body-sm` / `on-surface-variant`, action in `label-md` / `accent-ink`.
- `space-6` above, `space-3` below. No dividers; the spacing does the work.
